
## Cost and Loss Functions

### Loss Function

- Measures error for a **single prediction**
- Quantifies deviation between predicted and actual value
- Helps assess model accuracy **per data point**

### Cost Function

- Aggregates error across **all predictions**
- Represents **average loss** over the dataset
- Used to **optimize model** during training
- Ideal value is **zero or close to zero**
- Minimized using **gradient-based techniques**
