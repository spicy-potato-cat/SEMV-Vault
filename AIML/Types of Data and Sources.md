
## Types of Data

### 1. Structured Data
- Organized in rows and columns
#### 1) Numerical Data (Quantitative):
- Discrete Data Values
- Continuous Data Values

#### 2) Categorical Data (Qualitative)
- Nominal 
- Ordinal
### 2. Un-Structured Data
- Free-form no predefined schema (e.g. text, images, videos)
### 3. Time Series
- indexed by price (e.g., stock prices)

## Sources of Data

### 1. Primary Source
Data that is collected first hand for the purpose of training and testing the model itself
1) Web Scraping
2) API
3) Surveys/Interviews

### 2. Secondary Source
 Data that was collected for some other purpose but now it can be still used for training and testing the model because the data is still relevant for us. It is collected by someone other than the developer team
 1) Internal Data: Organization (e.g. Weather Data collected by a private organization)
 2) External Data: Government Agencies (e.g. Census of India)
 
## Qualities of Data
 3aV's
 1. Volume: Scale of data generated every second
 2. Variety: Different Formats (e.g., Video, Text, Images)
 3. Velocity: Speed of generation and processing
